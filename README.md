# 🎮 KBC Quiz Game (Python + Tkinter)

A GUI-based **Kaun Banega Crorepati (KBC)** style quiz game built using Python and Tkinter.
This project simulates a real quiz show experience with lifelines, timer pressure, and progressive rewards.

---

## 🚀 Features

* 🎯 **15 Question Full-Length Game**
* 🔀 **Randomized Questions (Shuffle Mode)**
* ⏳ **Timer for Each Question (15 seconds)**
* 🎨 **KBC-Themed GUI (Dark Mode Interface)**
* 💰 **Prize Ladder System**
* 🎯 **Answer Lock & Highlight Effect**
* 📊 **Audience Poll Lifeline**
* ☎️ **Phone a Friend Lifeline**
* ✂️ **50-50 Lifeline**
* ❌ **Game Ends on Wrong Answer or Timeout**

---

## 🛠️ Tech Stack

* **Python**
* **Tkinter (GUI Library)**
* **Random Module**

---

## ▶️ How to Run

1. Clone the repository:


git clone https://github.com/DEVANG-60/KBC-Game.git


2. Navigate to the project folder:


cd KBC-Game


3. Run the game:

```bash
python kbc_game.py
```

---

## 🧠 Game Logic Overview

* Questions are stored in a list format
* Questions are shuffled randomly for each game
* Timer counts down for each question
* Lifelines help the user answer difficult questions
* Money increases with each correct answer
* Game ends on:

  * Wrong answer ❌
  * Timer runs out ⏳
  * All questions answered 🏆
